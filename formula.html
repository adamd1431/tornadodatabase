Tornado estimate formula

This model starts with a structural wind estimate, adds decimal MPH boosts for contextual evidence, then applies a small confidence correction for documentation and uncertainty. The goal is to reduce bias by making every boost tied to a visible evidence category instead of overall impression.

Final = clamp(40, 245, (Structural + Exposure + Context Boost) x Confidence)
Structural = Rating Anchor + DI Offset + Construction Offset
Exposure = sparse-target correction for rural tracks
Context Boost = Ground + Vehicle + Vegetation + Debris + Radar + Path + Calculation Support
Confidence = Documentation x Uncertainty
