Contextual estimate model

Tornado estimate formula

This model works section by section. Structural DIs set the base, tree/ground/vehicle evidence adds contextual support, X-factor handles sparse-target violent clues, and confidence adjusts the final result using documentation, radar, and environment.

Final = softCeiling((Base DI + Adjusted Context) x Confidence, 245)
Base DI = max(Structural DI, Tree DI, Scouring DI, Vehicle DI)
Adjusted Context = (Supporting DIs + X-Factor) x structural headroom
Soft Ceiling = exponential approach toward 245 mph, not a hard cutoff
Confidence = Documentation x Radar Confidence x Environment x Uncertainty
