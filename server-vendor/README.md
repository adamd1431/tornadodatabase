# Server dependency

`jsfive-0.4.2.cjs` is the unchanged, self-contained CommonJS build from the official npm package `jsfive@0.4.2` (https://registry.npmjs.org/jsfive/-/jsfive-0.4.2.tgz), maintained at https://github.com/usnistgov/jsfive. It reads the NetCDF4/HDF5 subset generated by NOAA's original pressure-plot form. It is only imported by the server-side subset decoder.

The upstream license is retained in `jsfive-LICENSE.txt`; bundled pako copyright and MIT/Zlib notices remain in the source. No package install or runtime CDN is required.

`pdfjs-4.8.69/` contains the unchanged legacy `pdf.mjs`, `pdf.worker.mjs` and Apache-2.0 license from Mozilla's official `pdfjs-dist@4.8.69` package (https://registry.npmjs.org/pdfjs-dist/-/pdfjs-dist-4.8.69.tgz). The JTWC annual-report endpoint uses text extraction only, with evaluation and font rendering disabled. PDFs are fetched only from JTWC's fixed official report URLs. These files are server dependencies and are never imported by the browser.
